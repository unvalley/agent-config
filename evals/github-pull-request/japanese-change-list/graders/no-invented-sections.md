The repository has no PR template, so the PR body should be a bullet list of
changes, optionally preceded by one or two lines of context.

PASS if the PR body contains no section headings of its own.

FAIL if the PR body adds section headings such as 概要, 変更内容, 背景, テスト, or
確認事項. Labels that only separate the title from the body do not count as
section headings.
